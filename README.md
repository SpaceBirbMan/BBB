# Что это?

В данном репозитории запечетлена работа над системой для определения дисплазии тазобедренного сустава у детей до года. Проект коммандный и относится к хакатону.

**Один невнятный коммит здесь потому, что это резервный пуш, сделанный на скорую руку.** 
Нет ни одной причины его как-либо менять - это не внесёт ясности

# Что делает

В систему загружается снимок, она расставляет точки, проводит расчёты и устанавливает наличие и степень дисплазии. 
Система делится на frontend-часть, написанную с использованием React и backend-часть, содержащую сервисы для расчётов, обработки dicom-файлов и нейросетевой модуль

# Развёртывание

Не самое презентабельное, однако есть всё для запуска обоих частей + веса от нейросетей
